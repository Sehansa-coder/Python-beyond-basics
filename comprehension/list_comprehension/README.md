# Python comprehensions

-A comprehension is a short, powerful way to create collections (like lists, dictionaries, sets) using loops in one clean line.

- Comprehension provides a concise and readable way to create lists, dictionaries, and sets using a single line of code.

---

##  📌  Topics covered

- List comprehension
- Dictionary comprehension
- Set comprehension
- Conditional comprehension
- If-else inside comprehension
